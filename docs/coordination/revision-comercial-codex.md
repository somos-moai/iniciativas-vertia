# Revisión comercial final de Codex

15 de octubre de 2026. Borradores elaborados realmente mediante Claude Code. Codex consolidó alcance, cifras y entregables; Gemini mediante Antigravity tiene revisión pendiente, no atribuida como completada.

Se conciliaron las siete cuotas de cada iniciativa contra neto, IVA y total usando decimales exactos. Unidad contractual UF, USD solo de referencia; IVA de facturación sobre CLP. Todos los cargos de terceros durante desarrollo, pruebas y producción corresponden a Vertia. Las cuotas financian desarrollo y el soporte se propone por separado.

Se especificaron límites propuestos en lugar de usar expresiones abiertas como catálogo razonable o migración acotada. Se alinearon el registro básico de obligaciones incluido, la automatización avanzada futura y el conector POST unidireccional incluido si existe API documentada. El registro original de roadmap se conserva como fuente estructurada y se acompaña de un roadmap legible.

El renderer documental empaquetado se ejecutó y diagnosticó falta de soffice.exe. Windows no incluye LibreOffice en el runtime disponible; se utilizó Microsoft Word instalado para exportar los DOCX y Poppler del runtime para rasterizar todos los PDF. No se generó un PDF distinto del Word con un motor HTML que ocultara defectos del DOCX. Las dos propuestas tienen siete páginas; el cuadro financiero se mantuvo completo en una página. Se revisaron las imágenes de las páginas, los márgenes, la marca y las tablas.

No se enviaron documentos a contactos externos. La publicación para revisión se realizó en el dominio indicado por el usuario y dentro de su repositorio autorizado.
